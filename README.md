# Одностраничное резюме без контактов

Живая страница: **https://qwert11.github.io/resume3/** — копия
[resume](https://github.com/qwert11/resume), из которой убраны контакты.

## Зачем отдельная копия

Некоторые площадки не принимают резюме с контактами (Hubstaff Talent отклоняет PDF
с почтой и телефоном), а по правилам других ссылка на резюме с контактами равна их
передаче. Эту версию можно загружать и давать ссылкой туда, где контакты запрещены:

- нет почты, Telegram, GitHub и телефона — ни на странице, ни в PDF / Word / Markdown,
  ни во встроенных в страницу данных;
- нет ссылки на полное резюме (resume2) и на resume — в них контакты;
- в боковой колонке вместо «Контакти» — «Локація» с городом и форматом работы.

`scripts/build.py` проверяет страницу и экспорты каждого профиля и останавливает
сборку, если в них попали почта, `mailto:`, `t.me/`, телефон или ссылка на
resume / resume2.

## Откуда берутся данные

Здесь нет своей копии фактов. `scripts/fetch_source.py` при каждой сборке тянет
из `qwert11/resume2/data` только то, что нужно странице, — `master.yaml`,
`experience.yaml`, `education.yaml`, `languages.yaml` — и вырезает из `master.yaml`
блок `contacts:`. Скачанное кладётся в `data/` и коммитится как снимок: так сборка
переживает отсутствие сети, а `git diff` показывает, что изменилось в источнике.

Правки фактов вносятся в resume2, правки вёрстки — в resume и переносятся сюда.
Эта страница пересобирается: при пуше в свои файлы, по расписанию раз в сутки и
вручную через `workflow_dispatch`.

## Профили

Те же пять профилей, что и в resume, с переключателем над листом:

| Профиль | Адрес |
| --- | --- |
| Full | `/` |
| .NET | `/dotnet/` |
| Delphi | `/delphi/` |
| Web | `/web/` |
| AI / Python | `/ai/` |

У каждого профиля свой заголовок и описание, свои вехи, цифры, стек и записи
об образовании; PDF / Word / Markdown собираются в папке профиля.

## Что попадает на страницу

Одностраничник — это вехи, собранные из подробного резюме, а не его сжатая
копия. Мера: контент занимает половину листа — на профиль не больше пяти
пунктов, четыре группы стека, одна запись об образовании. Отбираем то, что
продаёт на рынке: масштаб, лидерство, современный стек. Отбор описан в
`onepager.yaml`, по одному блоку на профиль:

| Ключ | Смысл |
| --- | --- |
| `title_key`, `summary_key` | заголовок и краткое описание из `master.yaml` |
| `jobs` | какие позиции показать и какие пункты (по номеру в `experience.yaml`) считать вехами; `note: true` добавляет пометку о работодателе; остальные позиции сворачиваются в строку «Раніше» |
| `skills` | группы стека в боковой колонке. Только актуальная версия каждой технологии: `.NET 7`, а не `.NET 7 / 6 / 5`; история версий остаётся в полном резюме |
| `metrics` | какие четыре цифры вывести под кратким описанием (по значению из `master.yaml`) |
| `education` | номер записи из `education.yaml` |

## Сборка

```bash
pip install -r requirements.txt
python scripts/build.py              # с обновлением данных из resume2
python scripts/build.py --skip-fetch # из локального снимка
```

Результат — `output/site`: `index.html` и папки профилей, в каждой `resume.pdf` /
`.docx` / `.md` на английском и `resume.uk.*` на украинском. Кнопки скачивания переключаются
вместе с языком интерфейса. PDF собирается reportlab-ом в той же двухколоночной
раскладке и тоже помещается на одну страницу; сборка предупреждает, если колонка
не влезла.

## Вёрстка

- **Панель.** Закреплена сверху и не уезжает при прокрутке: слева профили,
  справа тема одной кнопкой по кругу (Авто → Світла → Темна), язык и экспорт
  выпадающими списками.
- **Лист.** Тёмная боковая колонка (локация, навыки, языки, образование) и
  основная (имя, описание, цифры, опыт). На экране лист имеет пропорции A4.
- **Печать.** `Ctrl+P` даёт ровно одну страницу A4 без полей: боковая колонка
  идёт на всю высоту, элементы управления скрыты, кегли переведены в пункты.
  Проверено headless Chrome для всех профилей на обоих языках.
- **Телефон.** Одна колонка от 320 px: сначала основная часть, ниже боковая.
- **Темы.** «Авто» — светлая с 07:00 до 19:59 по локальному времени, иначе тёмная.
- **Языки.** «Авто» — украинский для киевской таймзоны или `uk`-локали, иначе
  английский. Параметр `?lang=uk|en` в адресе принудительно задаёт язык.
